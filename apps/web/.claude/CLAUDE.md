# Design Context

**Register:** brand — the landing page is a marketing surface that communicates DevMatch's identity

**Brand Personality:** Minimal · Technical · Capable

**Palette:** Deep muted rose (oklch 0.50 0.18 330) primary on pure white/near-black architecture. See `DESIGN.md` for full token set.

**Key Principles:** Data as design, precision over polish, developer-first, intentional motion, restraint is the risk.

**Anti-Reference:** No generic SaaS — no warm-cream backgrounds, gradient hero buttons, floating mockups, template landing-page patterns.

**Reference:** Vercel — restrained, developer-first, confident without loudness.

See `PRODUCT.md` for full product strategy and `DESIGN.md` for complete visual system.
